Python Quiz Application
A simple command-line quiz application developed using Python.

Features
Player name input
Multiple-choice questions
Random question order
Automatic answer checking
Score calculation
Percentage calculation
Performance message
Play again option
Technologies Used
Python
Random module
Requirements
Python 3.x

No external libraries are required.

How to Run
Download or clone the project.
Open the project folder in VS Code or terminal.
Run:
python main.py

Enter your name.
Answer each question using A, B, C, or D.
View your final score.
